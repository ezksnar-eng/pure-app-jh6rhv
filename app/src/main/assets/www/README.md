# تطبيق مانجا بيور — نسخة 8

## جاوبتك: إي، احتجت معلومة، ولقيت السبب المحتمل الأقوى بنفسي
فحصت كود النسخة 7 اللي عطيتك بالماضي حرف حرف — **ماكو فيه أي سطر يحط بيانات وهمية**. يعني لو الصورة اللي بعتها بعد التحديث لسا نفسها، مو مشكلة بالكود نفسه، هذولي الاحتمالات المرتبة:

1. **الأرجح**: هذي الأعمال الثلاثة كانت *سبق وانخزنت فعلياً بذاكرة متصفحك المحلية (IndexedDB)* من وقت نسخة أقدم (كان فيها كود يحطهم لو فشل الاتصال بقاعدة البيانات). حذف الكود بالنسخة 7 يمنع تكرارهم بالمستقبل، بس **ما يمسح اللي انخزن مسبقاً بجهازك** — هذي نقطة فاتتني وصلحتها الحين: أضفت تنظيف تلقائي (مرة وحدة بس) يمسح أي بيانات محلية قديمة عند أول فتح للنسخة 8.
2. رفعت آخر تحديث فعلاً على Netlify؟ لو الرابط نفسه ما تغيّر، المتصفح ممكن يعرض نسخة JS قديمة من الكاش. أضفت رقم إصدار لروابط الملفات (`?v=8`) يجبر المتصفح يجيب النسخة الجديدة دائماً.
3. الاتصال بـFirebase لسا يفشل لسبب غير معروف عندي (قواعد الأمان، أو مشكلة شبكة).

## شلون تتأكد بنفسك هسه بثانية وحدة
افتح القائمة الجانبية (☰) — بالأسفل صار مكتوب بوضوح:
- **"نسخة 8 — متصلة بـFirebase"** = تمام، الاتصال شغّال.
- **"نسخة 8 — وضع محلي (ماكو اتصال بقاعدة بيانات)"** + رسالة حمراء تحتها = فيه مشكلة اتصال حقيقية، وبتشوف نص الخطأ بالضبط. ابعثلي لقطة شاشة لهذا السطر وأعرف السبب فوراً بدون تخمين.

إذا شفت "نسخة 7" أو رقم أقدم بنفس هذا المكان، معناها التحديث ما وصل فعلاً (مشكلة رفع/كاش)، مو مشكلة كود.

## الملفات
نفس بنية النسخة 7 (بدون أي شاشة رفع/إدارة). التعديل هذي المرة: تنظيف الذاكرة المحلية القديمة تلقائياً + رقم نسخة واضح بالقائمة الجانبية + منع كاش المتصفح للملفات.

## النشر
اسحب المجلد كامل على Netlify. بعد الرفع، افتح الرابط **بمتصفح خاص/تخفي (Incognito)** أول مرة للتأكد إنك تشوف أحدث نسخة فعلاً بدون أي كاش قديم يتدخل.
