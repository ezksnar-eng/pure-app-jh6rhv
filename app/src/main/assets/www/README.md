# تطبيق مانجا بيور — نسخة 6

## الوضع الحالي
- التطبيق **يعرض فقط** — ماكو أي شاشة إضافة/تعديل أعمال بداخله (انحذفت بناءً على طلبك، لأن التغذية صارت من قاعدة بيانات خارجية).
- قاعدة البيانات: **Firebase Firestore** (مشروع pure-library-2d45d)، معبّاة مسبقاً بملف `config.js`.
- مجموعة الأعمال اسمها **"مانغا"** — نفس المجموعة اللي تكتبلها أي أداة رفع خارجية (متل دالة `uploadMangaToFirebase`).
- أي حقل ناقص بمستند (type، status, latestChapter، إلخ) ينعبّى تلقائياً بقيمة افتراضية معقولة (`normalizeWork` بملف `store.js`)، فما تطلع بيانات ناقصة أو يتكسر العرض.

## الملفات
- `index.html` — الصفحة الرئيسية
- `styles.css` — كل التنسيقات (الوضع الفاتح/الداكن التلقائي من هنا)
- `config.js` — بيانات Firebase (مفعّلة) و Supabase (احتياط اختياري)
- `store.js` — طبقة التخزين + دالة التطبيع (تقرأ من مجموعة "مانغا")
- `app.js` — منطق التطبيق (بدون أي شاشة إدارة/رفع)
- `supabase-schema.sql` — يُستخدم بس لو رجعت تشتغل بـ Supabase بدل Firebase

## النشر على Netlify
اسحب المجلد كامل على Netlify — بدون أي بناء أو أوامر.

## قواعد أمان Firestore (خطوة لازمة مرة وحدة)
من Firebase Console ← Firestore Database ← Rules، الصق هذا واضغط نشر:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```
هذي قاعدة مفتوحة (قراءة وكتابة للكل) مناسبة لمرحلة التجربة الحالية.

## شكل بيانات "العمل" اللي يقرأه التطبيق من مجموعة "مانغا"
أي حقل مو موجود ينعبّى تلقائياً بقيمة افتراضية، فمو لازم ترسلهم كلهم:
```js
{
  title,                    // (لازم)
  cover,                    // رابط صورة أو Base64
  sourceUrl,                // رابط العمل الأصلي — يظهر كزر بصفحة التفاصيل
  sourceSite,                // اسم الموقع (يظهر كـ"المصدر")
  type,                      // "مانجا" | "مانهوا" | "مانها" — افتراضي "مانجا"
  status,                    // "مستمر" | "مكتمل" | "متوقف" — افتراضي "مستمر"
  latestChapter,              // نص متل "الفصل 5" — يُستخرج منه الرقم تلقائياً
  genres: [],                 // اختياري
  desc,                       // اختياري
  createdAt, updatedAt        // serverTimestamp() أو رقم عادي، الاثنين مدعومين
}
```

## نظام التحميل (يبقى شغّال)
من تبويب "الفصول" بأي عمل، لو فيه فصول مرفوعة بمجموعة `chapters` (مرتبطة بـ workId)، زر التحميل يحفظها على جهازك للقراءة بدون إنترنت — يظهر بقسم "تحميلاتي".

## مميزات القارئ الشخصية (محلية على كل جهاز، ما تتأثر بمصدر البيانات)
مفضلتي، قائمتي، القوائم المخصصة، تقييمي، آخر قراءاتي — كلها محفوظة بمتصفح كل مستخدم لحاله (localStorage)، بغض النظر شلون انحطت الأعمال بقاعدة البيانات.
